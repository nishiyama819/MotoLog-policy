# 個人情報保護方針

本アプリ「MotorcycleLogbook (MotoLog)」は、利用者の個人情報の保護を重要視し、以下の通りプライバシーポリシーを定めます。

## 1. 収集する情報
本アプリでは、以下のサービスを利用して匿名の統計データやクラッシュ情報を収集する場合があります。
- Google Firebase (Crashlytics) 
これらの情報は、アプリの品質向上および不具合修正のために利用され、個人を特定する情報は含まれません。

## 2. 広告について
本アプリでは、広告配信のためにGoogle AdMobを利用する場合があります。
AdMobは、ユーザーの興味に応じた広告を表示するために広告識別子等を利用することがあります。

## 3. データの保存
アプリ内に入力されたデータ（走行ログ、車両情報等）は、利用者の端末内にのみ保存されます。
バックアップ機能を利用した場合、データは利用者が指定した場所に保存されます。

本アプリの利用により生じた損害等について、開発者は一切の責任を負いません。
